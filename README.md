# AI Research Agent — 웹사이트 버전

연구 주제를 적으면 Claude가 **8단계**로 조사합니다. 계획을 세우고, 학술 데이터베이스를 검색하고, 근거를 평가해 종합한 뒤, 스스로 비판해 다시 조사하고, 보고서를 쓰고 인용을 검증합니다.
결과는 **PDF · Word · PowerPoint · Markdown** 등으로 내려받을 수 있습니다.
중간고사 때 만든 Colab 노트북 에이전트를 **설치 없이 주소만 열면 쓸 수 있는 웹사이트**로 옮긴 기말 프로젝트입니다.

- **사이트 주소**: https://imh247.github.io/ai-research-agent/
- **코드 저장소**: https://github.com/ImH247/ai-research-agent
- 서버가 없는 정적 사이트입니다(GitHub Pages). 조사 엔진은 **사용자의 브라우저 안에서** 돌아가고, Claude API는 사용자가 넣은 **본인 API 키**로 직접 호출합니다.

---

## 1. 바로 써 보기

### 키 없이 데모 보기 (비용 없음)
1. 사이트를 엽니다. 맨 위 **"처음 사용하시나요?"** 카드에서 **데모 실행 (약 45초)** 또는 **빠르게 (약 10초)** 를 누릅니다.
2. 미리 실제로 실행해 둔 조사 기록이 진행 화면에서 그대로 재생되고, 끝나면 결과 화면이 열립니다.
3. 결과 화면에서 보고서, 근거, 검증, 과정 탭을 보고 PDF·Word·PPT·Markdown으로 내려받아 봅니다.

왼쪽 사이드바 **기록**의 **샘플** 두 개("생성형 AI 활용이 대학원생의 연구 생산성과 연구 품질에 미치는 영향", "롤러를 활용한 센서 제작 공정")도 키 없이 바로 열립니다(사이드바가 접혀 있으면 맨 위 버튼으로 펼칩니다).
두 샘플은 2026-11-02에 Claude Opus 5.5로 실제 실행한 결과입니다.

### 실제로 조사하기 (본인 API 키 필요)
1. 왼쪽 사이드바 아래의 **설정**(톱니)을 눌러 Anthropic API 키를 넣습니다. 키는 [console.anthropic.com → API Keys](https://console.anthropic.com/settings/keys)에서 만듭니다.
2. 화면 아래쪽 입력창에 **연구 주제**를 적습니다. 예시 칩을 눌러 채울 수도 있고, **주제 다듬기**를 누르면 더 구체적인 주제 3개를 제안받습니다.
3. 오른쪽 **조사 설정**에서 **모델**, **조사 깊이**, **결과물 형식**과 고급 설정(검색 시작 연도, 보고서 언어, 최대 비용 등)을 고르고 **조사 시작**을 누릅니다. `Ctrl+Enter`로도 시작합니다.
4. 진행 화면에서 단계, 활동 기록, 비용, 남은 시간을 봅니다. "조사 계획을 먼저 검토하기"를 켰다면 계획을 고친 뒤 승인합니다.
5. 끝나면 결과 화면이 열립니다. 고른 형식은 버튼 한 번으로 내려받습니다.

> 처음에는 **빠르게 + Claude Haiku 5.5**로 시험해 보세요. 몇 분이면 끝나고 비용은 수십 센트 이하입니다.
> 표준 깊이 + Claude Opus 5.5는 약 12~24분, 약 $4입니다(실제 실행 2회 평균).

## 2. 기능

| 구분 | 기능 |
|---|---|
| 작성 | 주제 입력(최대 4,000자, 초안 자동 저장), 예시 주제, **주제 다듬기**(Claude Haiku 5.5가 구체적인 주제 3개 제안) |
| 설정 | **모델 선택**(Opus 5.5 · Sonnet 5.5 · Haiku 5.5 · Fable 5.2, 가격 표시, 키로 쓸 수 없는 모델은 막음), **조사 깊이**(빠르게 · 표준 · 깊게), **결과물 형식** 다중 선택, 고급 설정(검색 시작 연도, 보고서 언어, 재조사 횟수, 검색 범위, 인용 검증 수, 병렬 실행 수) |
| 예상치·한도 | 선택에 따른 LLM 호출 수 · 시간 · 비용 예상, **최대 비용(USD) 한도**: 한도에 닿으면 추가 조사를 멈추고 그때까지 모은 근거로 보고서를 씀 |
| 진행 | 8단계 진행 표시, 재조사 라운드, 하위 질문별 상태, 활동 기록, 보고서 작성 실시간 미리보기, 비용 막대, **남은 시간 추정**, **지금 마무리**(추가 검색을 멈추고 그때까지 모은 근거로 보고서 작성) |
| 사람 검토 | 조사 계획(하위 질문)을 고치거나 지우거나 추가한 뒤 승인, 또는 의견을 주고 다시 계획(고친 질문도 함께 반영) |
| 실행 보호 | 진행 중 탭을 닫으려 하면 경고, 단계마다 자동 저장, 멈춘 조사는 **이어서 진행**(키 오류·크레딧 부족으로 멈춘 조사도 키를 고치거나 충전한 뒤 이어서 진행), 다른 탭에서 열려 있으면 **이 탭에서 계속하기**로 넘겨받기 |
| 알림 | 끝나거나 검토가 필요하면 데스크톱 알림과 소리(선택), 탭 제목에 진행률 표시 |
| 결과 | 보고서(목차, 인용 칩에 출처 카드), 근거(차트, 필터, 표, 문헌 상세), 인용 검증(수정 전 → 수정 후), 과정(이해 · 계획 · 자기 비판 · 타임라인), **질문하기**(이 조사의 근거만으로 답하는 대화) |
| 내려받기 | PDF(인쇄 창의 "PDF로 저장"), Word(.docx), PowerPoint(.pptx), Markdown, HTML, BibTeX, RIS, CSV, JSON |
| 다시 쓰기 | **보고서 다시 쓰기**: 언어 · 분량 · 모델 · 추가 요청을 바꿔 ⑦ 보고서 작성과 ⑧ 인용 검증만 다시 실행(검색은 다시 하지 않음) |
| 기록 | 왼쪽 사이드바(펼치고 접을 수 있음)에서 실행 기록 보기·검색, 이름 바꾸기, 삭제, **조사 파일 저장·열기**(다른 컴퓨터에서 결과 다시 보기, 창에 끌어다 놓기 지원) |
| 데모 | 키 없이 실제 실행 기록 재생(보통 속도 약 45초, 빠르게 약 10초) |

### 8단계 조사 과정
① 주제 이해 → ② 조사 계획(+사람 검토) → ③ 자료 탐색(도구 호출 반복) → ④ 자료 평가 → ⑤ 종합(RAG) → ⑥ 자기 비판·재조사(③으로 되돌아감) → ⑦ 보고서 작성 → ⑧ 인용 검증·수정

검색 도구: **OpenAlex**, **Semantic Scholar**, **Europe PMC**(학술 데이터베이스), **Claude 웹 검색**(Anthropic 서버 도구).

## 3. API 키와 보안

이 사이트에는 서버가 없습니다. GitHub Pages는 HTML·JavaScript 파일만 내려 주고, 키를 받거나 저장하는 곳이 없습니다.

- **키는 이 브라우저에만 있습니다.** 기본은 탭을 닫으면 지워지는 `sessionStorage`이고, 설정 창(왼쪽 톱니 아이콘)에서 "이 브라우저에 저장"을 켤 때만 `localStorage`에 남습니다.
- **키는 `api.anthropic.com`으로만 전송됩니다.** 페이지의 Content-Security-Policy가 브라우저에서 연결할 수 있는 곳을
  `api.anthropic.com`, `api.openalex.org`, `api.semanticscholar.org`, `www.ebi.ac.uk` 네 곳으로 막습니다(외부 스크립트·CDN도 없음).
- 키는 실행 기록, 이벤트, 오류 메시지, 내려받은 파일, 조사 파일 어디에도 들어가지 않습니다(테스트로 확인).
- 권장 사항
  - 평가용으로 **사용 한도(spend limit)를 낮게 건 별도 키**를 만들어 쓰고, 다 쓰면 콘솔에서 키를 삭제하세요.
  - 공용 컴퓨터에서는 "이 브라우저에 저장"을 켜지 말고, 다 쓰면 설정 창에서 **지우기**를 누르세요.
  - GitHub Pages에서는 같은 계정의 다른 사이트(`<아이디>.github.io/<다른 저장소>`)가 같은 출처라서 `localStorage`를 함께 씁니다. 기본값(탭을 닫으면 지워지는 `sessionStorage`)으로 쓰면 다른 사이트가 키를 읽을 수 없습니다.
- 브라우저에서 API를 직접 부르기 위해 공식 SDK의 `dangerouslyAllowBrowser` 옵션을 씁니다. 이 옵션은 "다른 사람에게 내 키를 넣은 페이지를 배포하지 말라"는 경고이고,
  이 사이트처럼 **각자 자기 키를 넣는 방식(BYOK)** 에서는 키가 그 사람의 브라우저 밖으로 나가지 않습니다.

## 4. 비용

비용은 넣은 키의 Anthropic 계정에 청구됩니다. 화면의 예상 비용과 진행 중 비용은 토큰 수와 웹 검색 횟수로 계산한 **대략치**입니다(예상 비용에는 깊이별로 어림한 웹 검색 횟수의 요금도 들어갑니다).

| 모델 | 입력 / 출력 (100만 토큰당 USD) | 용도 |
|---|---|---|
| Claude Opus 5.5 (기본) | $4 / $20 | 깊은 분석과 비용의 균형 |
| Claude Sonnet 5.5 | $2 / $10 | 빠르고 경제적 |
| Claude Haiku 5.5 | $0.10 / $0.50 | 가장 빠르고 저렴, 시험 실행 |
| Claude Fable 5.2 | $8 / $40 | 최고 성능, 가장 비쌈 |

- 웹 검색은 1,000회에 $10이 따로 붙습니다. 가격 기준일은 2026-11-03입니다(`assets/js/engine/models.js`).
- 깊이별 예상 시간: 빠르게 5~9분 · 표준 12~24분(실측) · 깊게 20~40분(Opus 5.5 기준; 빠르게·깊게는 추정).
- **최대 비용** 칸에 한도를 정해 두면 그 금액에 닿을 때 추가 조사를 멈추고 보고서를 마무리합니다.

## 5. 데이터는 어디에 저장되나요

- 실행 기록은 **이 브라우저의 IndexedDB**에만 저장됩니다. 다른 사람이나 다른 컴퓨터에서는 보이지 않습니다.
- 다른 컴퓨터로 옮기려면 결과 화면이나 기록 메뉴에서 **조사 파일 저장**(.json) → 다른 곳에서 **조사 파일 열기**(또는 창에 끌어다 놓기).
- 시크릿(사생활 보호) 창이나 저장소가 막힌 브라우저에서는 탭을 닫으면 기록이 사라집니다(화면 위에 안내가 뜹니다).
- 한 번에 **한 탭**에서만 열립니다(두 탭이 같은 기록을 동시에 고치지 않도록). 다른 탭에서 이미 열려 있으면 안내가 뜨고, **이 탭에서 계속하기**를 누르면 그 탭에 진행 중인 조사가 없을 때 이 탭으로 넘겨받습니다.
- 조사는 탭이 열려 있는 동안 진행됩니다. 탭을 닫거나 새로고침하면 멈추지만, 단계마다 저장되므로 다시 열어 **이어서 진행**할 수 있습니다.

## 6. 중간고사(Colab) 버전과 달라진 점

| | 중간고사 Colab 노트북 | 이 웹사이트 |
|---|---|---|
| 실행 방법 | Colab에서 셀 실행, 코드 맨 위에 설정 입력 | 주소를 열고 화면에서 입력·선택 |
| 키 입력 | 노트북 셀 또는 Colab 보안 비밀 | 설정 창(브라우저에만 저장) |
| 검색 도구 | OpenAlex, Semantic Scholar, arXiv, Europe PMC, DuckDuckGo | OpenAlex, Semantic Scholar, Europe PMC, **Claude 웹 검색** |
| 결과물 | Markdown, HTML 보고서, 근거 표 CSV, 실행 기록 JSON(Colab 폴더에 ZIP으로 저장) | PDF, Word, PowerPoint, Markdown, HTML, BibTeX, RIS, CSV, JSON |
| 새 기능 | — | 주제 다듬기, 계획 검토, 비용 한도, 남은 시간, 이어서 진행, 알림, 보고서 다시 쓰기, 질문하기, 조사 파일, 기록 검색, 데모 |

- arXiv와 DuckDuckGo는 브라우저에서 다른 사이트의 요청을 받아 주지 않아(CORS 미지원) 직접 부를 수 없습니다. 그래서 arXiv는 빼고, 일반 웹 검색은 Anthropic의 웹 검색 서버 도구로 바꿨습니다.
- PDF는 브라우저의 인쇄 창에서 "PDF로 저장"으로 만듭니다(브라우저에는 PDF 엔진이 없음).
- 조사 로직, 프롬프트, 점수 가중치, 임계값은 실제 API로 검증한 파이썬 구현(`docs/reference/python/`)을 그대로 옮겼습니다.

## 7. 직접 실행하기 (로컬)

`index.html`을 더블클릭해 `file://`로 열면 동작하지 않습니다(브라우저가 파일에서 JavaScript 모듈을 불러오지 못하게 막음). 아무 정적 서버로 폴더를 열면 됩니다.

```
python -m http.server 8000
```

이 폴더에서 위 명령을 실행하고 브라우저에서 `http://localhost:8000/`을 엽니다. 설치할 패키지는 없습니다.

- **테스트 모드**: 주소 뒤에 `?mock=1`을 붙이면(`http://localhost:8000/?mock=1`) 가짜 모델과 가짜 검색 도구로 전체 흐름을 확인합니다. 실제 API를 부르지 않고 키도 필요 없습니다.
- **자동 테스트**: Node.js 22 이상에서 `npm test`(= `node --test tests/`). 네트워크와 API 키 없이 엔진, 결과물, 브라우저 백엔드를 확인합니다.

## 9. 알려진 제한

- 조사는 브라우저 탭이 열려 있어야 진행됩니다. 탭을 오래 숨겨 두면 브라우저가 타이머를 늦춰 화면 갱신이 늦어질 수 있습니다.
- 학술 데이터베이스(OpenAlex, Semantic Scholar, Europe PMC)는 공개 API라 요청이 몰리면 잠시 실패할 수 있습니다. 실패한 도구는 기록에 남고 다른 도구로 계속 진행합니다.
- 비용과 시간은 대략치입니다. 실제 청구액은 Anthropic 콘솔에서 확인하세요.
